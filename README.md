# Danial Ahmed · Portfolio 2.0

Mehrseitiges, statisches Portfolio für GitHub Pages. Die bisherige Portfolio-Version bleibt in ihrem eigenen Repository unangetastet.

## Seiten

- `index.html` – Startseite und berufliche Positionierung
- `profil.html` – Profil und Werdegang
- `kompetenzen.html` – technische und persönliche Kompetenzen
- `projekte.html` – ausgewählte Praxisprojekte mit GitHub-Links
- `zertifikate.html` – relevante Zertifikate, Nachweise und Credly-Link
- `kontakt.html` – Kontaktwege und gesuchte Rollen

## Lokal ansehen

Die Seite besteht aus HTML, CSS und JavaScript ohne Build-Schritt. `index.html` kann direkt im Browser geöffnet oder mit einem beliebigen statischen Webserver bereitgestellt werden.

## Veröffentlichung

Die Website ist für GitHub Pages unter dem Repository `portfolio-2.0` vorgesehen. Änderungen an der LinkedIn-Profilverknüpfung und die Aktivierung der Veröffentlichung erfolgen nach abschließender Sichtprüfung.
